# FORECAST

Sistem peramalan penjualan menggunakan metode ARIMA. Aplikasi ini dibuat untuk melakukan peramalan terhadap data penjualan sehingga dapat membantu melihat pola dan memperkirakan penjualan pada periode berikutnya.
# Fitur
- Input data penjualan
- Pengolahan data penjualan
- Analisis data penjualan
- Peramalan penjualan menggunakan metode ARIMA
- Menampilkan hasil peramalan
# Tools & Teknologi
- Python
- ARIMA
  
# Cara Menjalankan
1. Clone repositori ini
2. Install library yang diperlukan
3. Jalankan aplikasi/program
4. Masukkan data penjualan yang digunakan
5. Jalankan proses peramalan menggunakan metode ARIMA

## Hasil

Sistem menghasilkan nilai peramalan penjualan berdasarkan data historis yang digunakan sebagai input.
